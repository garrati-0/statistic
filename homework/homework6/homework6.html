#6 Online Algorithms: Recurrence Formulas for Mean and Variance

In data analysis, we often work with data streams where numbers arrive one at a time. The "naive" way to calculate mean and variance is to store all the data, and when asked, iterate over the entire list. This is inefficient, especially for large datasets or real-time systems. A much better approach is to use recurrence formulas, also known as "online algorithms." These formulas allow us to update the mean and variance with each new data point, using only the previous state.

1. Recurrence Formula for the Mean

Let $\bar{x}_n$ be the mean of $n$ data points. The standard definition is:

$$ \bar{x}_n = \frac{1}{n} \sum_{i=1}^n x_i $$

We can split this sum into the sum of the first $n-1$ points and the new point, $x_n$:

$$ \bar{x}_n = \frac{1}{n} \left( \left( \sum_{i=1}^{n-1} x_i \right) + x_n \right) $$

We know that the sum of the first $n-1$ points is related to the previous mean, $\bar{x}_{n-1}$, by $\sum_{i=1}^{n-1} x_i = (n-1)\bar{x}_{n-1}$. Let's substitute this in:

$$ \bar{x}_n = \frac{1}{n} \left( (n-1)\bar{x}_{n-1} + x_n \right) $$

Distributing the $\frac{1}{n}$, we get:

$$ \bar{x}_n = \frac{n-1}{n}\bar{x}_{n-1} + \frac{1}{n}x_n $$

This is a valid recurrence formula, but we can simplify it to a more intuitive form by writing $\frac{n-1}{n}$ as $(1 - \frac{1}{n})$:

$$ \bar{x}_n = (1 - \frac{1}{n})\bar{x}_{n-1} + \frac{1}{n}x_n = \bar{x}_{n-1} - \frac{1}{n}\bar{x}_{n-1} + \frac{1}{n}x_n $$

Finally, we group the last two terms to get the simplest recurrence relation for the mean:

Formula: $\bar{x}_n = \bar{x}_{n-1} + \frac{1}{n}(x_n - \bar{x}_{n-1})$

This formula is simple and elegant. It says the new mean is the old mean plus a small correction. The correction is the difference between the new value and the old mean, scaled by $\frac{1}{n}$. To use this, you only need to keep track of two numbers: the current count $n$ and the current mean $\bar{x}_n$.

2. Recurrence Formula for the Variance

Deriving the variance recurrence is more complex. A naive approach can suffer from "catastrophic cancellation," a numerical stability problem. The standard, robust method is Welford's online algorithm.

This algorithm tracks $n$ (count), $\bar{x}_n$ (mean), and a new quantity, $M_{2,n}$, which is the sum of squares of differences from the current mean:

$$ M_{2,n} = \sum_{i=1}^n (x_i - \bar{x}_n)^2 $$

The (population) variance is simply $\sigma_n^2 = M_{2,n} / n$, and the sample variance is $s_n^2 = M_{2,n} / (n-1)$. So, if we can find a recurrence for $M_{2,n}$, we can find the variance.

The derivation is involved, but it leads to this simple and powerful recurrence for $M_{2,n}$:

Formula: $M_{2,n} = M_{2,n-1} + (x_n - \bar{x}_{n-1})(x_n - \bar{x}_n)$

The Full Algorithm (Mean & Variance)

To calculate the mean and variance in a single pass, you only need to store three values: $n$ (count), $\bar{x}$ (mean), and $M_2$ (sum of squares).

Initialize: $n=0$, $\bar{x}=0$, $M_2=0$.

When a new value $x_n$ arrives:

  1. $n \leftarrow n + 1$
  2. $\delta \leftarrow x_n - \bar{x}_{n-1}$ (Difference from old mean)
  3. $\bar{x}_n \leftarrow \bar{x}_{n-1} + \delta / n$ (Update mean)
  4. $\delta_2 \leftarrow x_n - \bar{x}_n$ (Difference from new mean)
  5. $M_{2,n} \leftarrow M_{2,n-1} + \delta \cdot \delta_2$ (Update sum of squares)

After each step, the variance can be found:

  • Sample Variance: $s_n^2 = M_{2,n} / (n-1)$ (for $n > 1$)
  • Population Variance: $\sigma_n^2 = M_{2,n} / n$

Online Algorithm in C

Below is a C program that implements Welford's online algorithm. It uses a struct to hold the state ($n$, $\bar{x}$, $M_2$) and updates this state as new numbers are provided by the user, printing the new mean and variance each time.

// Include necessary libraries
#include <stdio.h>
#include <stdlib.h>

// A struct to hold the state of our "online" calculation
typedef struct {
    long long count; // n
    double mean;      // x_bar_n
    double m2;        // M_2,n (Sum of squares of diffs)
} WelfordState;

// Initialize a new state
void init_state(WelfordState *state) {
    state->count = 0;
    state->mean = 0.0;
    state->m2 = 0.0;
}

// Update the state with a new value using the recurrence formulas
void update_state(WelfordState *state, double newValue) {
    state->count++;
    
    double delta = newValue - state->mean;
    double newMean = state->mean + delta / state->count;
    double delta2 = newValue - newMean;
    
    state->m2 += delta * delta2;
    state->mean = newMean;
}

// Get the current sample variance from the state
double get_variance(WelfordState *state) {
    if (state->count < 2) {
        return 0.0; // Variance is undefined for n < 2
    }
    return state->m2 / (state->count - 1);
}

// Get the current mean from the state
double get_mean(WelfordState *state) {
    return state->mean;
}

int main(void) {
    WelfordState state;
    init_state(&state);
    
    double data[] = {10, 20, 22, 25, 26, 28, 30, 150};
    int n = sizeof(data) / sizeof(data[0]);

    printf("--- Welford's Online Algorithm ---\n");
    printf("Input | Count |      Mean | Sample Var.\n");
    printf("---------------------------------------\n");

    for (int i = 0; i < n; i++) {
        update_state(&state, data[i]);
        printf(
            "%5.0f | %5lld | %10.3f | %10.3f\n",
            data[i],
            state.count,
            get_mean(&state),
            get_variance(&state)
        );
    }
    
    printf("---------------------------------------\n");
    printf("Final Mean: %.3f\n", get_mean(&state));
    printf("Final Sample Variance: %.3f\n", get_variance(&state));
    
    return 0;
}

This C code cleanly separates the state (WelfordState) from the logic (update_state). This method is not only memory-efficient (it doesn't store the data) but also numerically stable, making it ideal for real-world statistical libraries and applications.
