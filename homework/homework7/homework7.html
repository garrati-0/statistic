#7 Security Simulation, Random Walks, and Binomial Convergence

This homework simulates the security of a server over n weeks. Each week, m attackers attempt to breach the server, each with a probability p of success.

  • If the server remains secure (all m attackers fail), its cumulative score increases by +1.
  • If the server is breached (at least one attacker succeeds), the score decreases by -1.

This process is a direct parallel to a 1D Random Walk. We will run thousands of trajectories (simulations) to observe the distribution of final scores. We will compare this empirical distribution with the theoretical Binomial distribution to see how the simulated data converges to the mathematical model as n and m increase.
