#5 Understanding Averages: Which "Measure of Location" is Best?

In statistics, we often want to summarize a large set of data with a single value. This value, which describes the "center" or "typical" data point, is called a measure of location or measure of central tendency. The word "average" is a non-technical term for this. But as it turns out, there are several different ways to calculate this "center," and the one you choose matters—a lot.

1. The Arithmetic Mean (The "Average")

This is what most people think of as the "average." You calculate it by adding up all the values in a dataset and then dividing by the number of values.

Formula: Mean = (x₁ + x₂ + ... + xₙ) / n

  • When is it useful? The mean is excellent for data that is symmetrically distributed (like a "bell curve") and doesn't have extreme outliers. For example, the average height in a classroom or the average test score (assuming no one got a 0).
  • When is it misleading? The mean is extremely sensitive to outliers (exceptionally high or low values). If you have a dataset of salaries [50k, 60k, 55k, 70k, 1,000k], the mean salary is 247k. This is not representative of a typical employee, as it's heavily skewed by the one 1,000k salary.

2. The Median (The Middle Ground)

The median is the "middle" value in a dataset that has been sorted from smallest to largest. If the dataset has an even number of values, the median is the mean of the two middle values.

  1. Step 1: Sort the data (e.g., [1, 5, 2] becomes [1, 2, 5]).
  2. Step 2: Find the middle value. In [1, 2, 5], the median is 2.
  3. Step 3 (Even set): In [1, 2, 5, 8], the middle values are 2 and 5. The median is (2 + 5) / 2 = 3.5.
  • When is it useful? The median is the "go-to" average when your data is skewed or has outliers. This is why you always hear about "median income" or "median house price." In our salary example [50k, 55k, 60k, 70k, 1,000k], the median is 60k. This is a much better representation of a "typical" salary than the mean of 247k.

3. The Mode (The Most Popular)

The mode is simply the value that appears most frequently in the dataset. A dataset can have no mode (if all values are unique) or multiple modes (e.g., "bimodal").

In the set [1, 2, 2, 3, 4, 4, 5], the modes are 2 and 4.

  • When is it useful? The mode is the only measure of central tendency that works for categorical data (non-numerical data). For example, the "average" t-shirt size sold is the mode (e.g., "Large"). It's also useful for finding "peaks" in data.

Other Proposed Averages

The "big three" aren't the only options. Others are useful in specific circumstances:

  • Geometric Mean: Used for data that represents growth rates or ratios (e.g., average investment return over several years).
  • Harmonic Mean: Used for averaging rates or speeds (e.g., calculating your average speed over a round trip).
  • Trimmed Mean: A compromise between the mean and median. You "trim" a certain percentage (e.g., 10%) of the highest and lowest values, then calculate the mean of what's left. This reduces the effect of outliers.

Conclusion: So Which is Best?

There is no single "best" average. The most useful one depends entirely on your data and the question you are trying to answer.

  • For symmetrical data with no outliers: Use the Mean.
  • For skewed data or data with outliers: Use the Median.
  • For categorical data or finding the most common value: Use the Mode.

Calculating Averages in C

The simulation above provides an interactive way to explore averages. Below is a simple C program demonstrating how to calculate the mean, median (which requires sorting), and mode from a basic integer array.

// Include necessary libraries
#include <stdio.h>
#include <stdlib.h> // For qsort
#include <string.h> // For memset

// Comparison function for qsort (for integers)
int compare(const void *a, const void *b) {
    return (*(int*)a - *(int*)b);
}

// 1. Calculates the Mean
double calculate_mean(int data[], int n) {
    double sum = 0.0;
    for (int i = 0; i < n; i++) {
        sum += data[i];
    }
    return sum / n;
}

// 2. Calculates the Median (Assumes data is already sorted)
double calculate_median(int sorted_data[], int n) {
    if (n % 2 == 1) {
        // Odd number of elements
        return sorted_data[n / 2];
    } else {
        // Even number of elements
        return (sorted_data[n / 2 - 1] + sorted_data[n / 2]) / 2.0;
    }
}

// 3. Calculates the Mode (Assumes data is already sorted)
int calculate_mode(int sorted_data[], int n) {
    int mode = sorted_data[0];
    int max_count = 0;
    
    int current_val = sorted_data[0];
    int current_count = 0;

    for (int i = 0; i < n; i++) {
        if (sorted_data[i] == current_val) {
            current_count++;
        } else {
            if (current_count > max_count) {
                max_count = current_count;
                mode = current_val;
            }
            current_val = sorted_data[i];
            current_count = 1;
        }
    }
    
    // Check the last run
    if (current_count > max_count) {
        max_count = current_count;
        mode = current_val;
    }
    
    return mode;
}

int main(void) {
    int data[] = {10, 20, 22, 25, 26, 28, 30, 30, 40, 150};
    int n = sizeof(data) / sizeof(data[0]);

    printf("Data: [10, 20, 22, 25, 26, 28, 30, 30, 40, 150]\n");
    printf("Total elements: %d\n", n);

    // --- Mean ---
    double mean = calculate_mean(data, n);
    printf("1. Mean: %.2f\n", mean);
    
    // --- Median ---
    // We must sort the data to find the median and mode
    qsort(data, n, sizeof(int), compare);
    double median = calculate_median(data, n);
    printf("2. Median: %.2f\n", median);

    // --- Mode ---
    int mode = calculate_mode(data, n);
    printf("3. Mode: %d\n", mode);

    printf("\nNotice the Mean (38.10) is pulled up by the outlier (150),\n");
    printf("while the Median (27.00) is a better 'center' for this data.\n");

    return 0;
}

This C code shows the fundamental logic. The qsort function is essential for finding the median. Once the data is sorted, finding both the median and the mode becomes a much simpler task. As the output of this C code notes, the mean is sensitive to the 150 outlier, while the median is "robust" to it.
