#8 The Thread of Recurrence: Connecting Statistics, Combinatorics, and Sequences

This homework explores a fascinating set of analogies. Our previous work (like hmwk6) focused on **statistical recurrence** for calculating the mean and variance. This was an *online algorithm* to summarize a stream of data. Now, we look at **combinatorial recurrence**, which is a way to *construct* mathematical objects. The common thread is the idea of building a new state based on one or more previous states.

The Foundation: Bernoulli Trials and the Binomial Distribution

This entire discussion starts with the Bernoulli process, which you mentioned. A Bernoulli process is a sequence of independent trials, each with two possible outcomes (e.g., "success" or "failure") and a constant probability of success ($p$).

Simulating a Bernoulli process (like flipping a coin) many times and tracking the average number of successes is how you demonstrate the Law of Large Numbers (LLN). The sample mean $\bar{x}_n$ converges to the true probability $p$.

But what if we ask a different question? Instead of the long-run average, what is the probability of getting *exactly* $k$ successes in $n$ trials? This is the Binomial Distribution: $$ P(X=k) = \binom{n}{k} p^k (1-p)^{n-k} $$

1. Binomial and Combinatorial Coefficients

The most important part of that formula is the binomial coefficient, $\binom{n}{k}$. This is a combinatorial coefficient that answers the question: "How many ways can we choose $k$ items from a set of $n$ items?"

In our Bernoulli process, it represents the number of different sequences (paths) that result in exactly $k$ successes. For example, to get 2 successes in 3 trials, you could have (Success, Success, Fail), (Success, Fail, Success), or (Fail, Success, Success). There are $\binom{3}{2} = 3$ ways.

2. Pascal's Triangle: A Recurrence for Coefficients

How do we calculate $\binom{n}{k}$? We can use the factorial formula $\frac{n!}{k!(n-k)!}$, but a more elegant way is with a recurrence relation. This relation forms Pascal's Triangle.

Any number in the triangle is the sum of the two numbers directly above it. This defines the recurrence for binomial coefficients:

$$ \binom{n}{k} = \binom{n-1}{k-1} + \binom{n-1}{k} $$

This is the core connection. We've moved from a statistical process (Bernoulli) to a pure combinatorial structure (Pascal's Triangle) defined by a recurrence.

3. Binomial Expansion

Why is it called a "binomial coefficient"? Because these are precisely the coefficients you get in the algebraic binomial expansion:

$$ (x+y)^n = \sum_{k=0}^n \binom{n}{k} x^{n-k} y^k $$

Notice the $n$-th row of Pascal's Triangle gives you the coefficients for $(x+y)^n$.

  • $(x+y)^2 = \mathbf{1}x^2 + \mathbf{2}xy + \mathbf{1}y^2$ (Row 2: 1, 2, 1)
  • $(x+y)^3 = \mathbf{1}x^3 + \mathbf{3}x^2y + \mathbf{3}xy^2 + \mathbf{1}y^3$ (Row 3: 1, 3, 3, 1)

4. The Fibonacci Sequence

The Fibonacci sequence is another famous structure defined by a recurrence: $F_n = F_{n-1} + F_{n-2}$. It seems unrelated, but it's beautifully hidden inside Pascal's Triangle. If you sum the "shallow diagonals" of the triangle, you get the Fibonacci sequence!

This leads to a combinatorial identity: $F_{n+1} = \sum_{k=0}^{\lfloor n/2 \rfloor} \binom{n-k}{k}$.

Analogies and Differences with Previous Homework

Let's compare this homework (hmwk8) with the one on recurrence formulas for mean/variance (hmwk6).

  • Similarity: Both are built on Recurrence. This is the central analogy.
    • hmwk6 (Variance): $M_{2,n} = M_{2,n-1} + (x_n - \bar{x}_{n-1})(x_n - \bar{x}_n)$. The new state depends on the previous state ($M_{2,n-1}, \bar{x}_{n-1}$) and a new input ($x_n$).
    • hmwk8 (Pascal): $\binom{n}{k} = \binom{n-1}{k-1} + \binom{n-1}{k}$. The new state depends entirely on two values from the previous state (the row above).
    • hmwk8 (Fibonacci): $F_n = F_{n-1} + F_{n-2}$. The new state depends on the two previous states.
  • Difference: Statistics vs. Combinatorics.
    • hmwk6 is a statistical algorithm. Its purpose is to summarize a stream of arbitrary, observed data. The recurrence is a tool for computational efficiency.
    • hmwk8 is a combinatorial (or generative) algorithm. Its purpose is to construct a precise, theoretical, and exact mathematical object. The recurrence is a *definition* of the object itself.
  • Difference: Process.
    • hmwk6 is an "online" algorithm that processes a single path or sequence of data as it arrives.
    • hmwk8 (Pascal's) is a "dynamic programming" algorithm that builds a *whole table* of solutions, where each solution (a coefficient) is built from previous solutions.

Generating Pascal's Triangle in C

This C program demonstrates the core recurrence $\binom{n}{k} = \binom{n-1}{k-1} + \binom{n-1}{k}$. It builds a 2D array representing the triangle, where each new element is the sum of the two elements from the row above it, perfectly illustrating the concept of building from a previous state.

// Include necessary libraries
#include <stdio.h>
#include <stdlib.h> // For dynamic allocation

// Function to calculate a single binomial coefficient (nCk)
// Note: This is the factorial method, not the recurrence, for the calculator part.
long long nCr(int n, int k) {
    if (k < 0 || k > n) {
        return 0;
    }
    if (k == 0 || k == n) {
        return 1;
    }
    // Optimize by choosing the smaller k
    if (k > n / 2) {
        k = n - k;
    }
    
    long long res = 1;
    for (int i = 1; i <= k; ++i) {
        res = res * (n - i + 1) / i;
    }
    return res;
}


// Function to print Pascal's Triangle using the recurrence
void printPascalsTriangle(int numRows) {
    // We use long long to prevent overflow for larger rows
    long long **triangle = (long long **) malloc(numRows * sizeof(long long *));
    
    printf("--- Pascal's Triangle (n=%d) ---\n", numRows);

    for (int n = 0; n < numRows; n++) {
        triangle[n] = (long long *) malloc((n + 1) * sizeof(long long));
        
        // Print leading spaces for alignment
        for (int s = 0; s < numRows - n - 1; s++) {
            printf("   ");
        }

        for (int k = 0; k <= n; k++) {
            // Base cases: C(n, 0) and C(n, n) are always 1
            if (k == 0 || k == n) {
                triangle[n][k] = 1;
            } else {
                // The Recurrence Relation!
                // C(n, k) = C(n-1, k-1) + C(n-1, k)
                triangle[n][k] = triangle[n - 1][k - 1] + triangle[n - 1][k];
            }
            printf("%6lld", triangle[n][k]); // Print with padding
        }
        printf("\n");
    }
    
    // Free allocated memory
    for (int i = 0; i < numRows; i++) {
        free(triangle[i]);
    }
    free(triangle);
}

int main(void) {
    int n = 10;
    printPascalsTriangle(n);
    
    printf("\n--- Combinatorics Calculator ---\n");
    int test_n = 7;
    int test_k = 3;
    printf(
        "C(%d, %d) = %lld\n",
        test_n, test_k,
        nCr(test_n, test_k)
    );
    
    return 0;
}

This C code cleanly demonstrates the generative power of recurrence relations. The statistical algorithm from hmwk6 *consumes* data to find a summary, while this combinatorial algorithm *generates* data to build a structure.
